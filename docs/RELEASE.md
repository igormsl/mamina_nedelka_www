## Режимы публичного пакета

**Решение 19.10:** отдельно разрешён `--blog-release`: индексировать каталог и 50 статей,
сохранив реальные статусы рецензий. Главная/служебные страницы noindex. Продуктовые проверки
не блокируют этот режим и не объявляются выполненными. Актуальная операция и её
sudo-команды — [INDEXING](INDEXING.md). Исторические операции ниже повторно не выполнять.

- `--public-preview --output <пустой каталог>` — разрешённое предварительное включение. Все страницы сохраняют noindex, видимый статус предварительной версии и отметки незавершённых проверок. Нужны подтверждённые `owner_visual_acceptance`, `public_enable_approved`, `vps_backup_and_rollback_plan`.
- `--release --output <пустой каталог>` — индексируемый выпуск после всех условий `release-checklist.json` и реальных рецензий `status: approved` + `review_evidence` каждой статьи. Предварительное включение не закрывает [правовые вопросы](LEGAL.md), [Telegram-сценарий](FUNNEL.md) и медицинские рецензии.

Обычный локальный `preview` не копируется в production. Публичный предварительный пакет собирается отдельно и проверяется `scripts/check_site.py --root <пакет> --mode public-preview`. `noindex` ограничивает индексирование, но не является защитой от доступа: страницы предварительной версии доступны любому посетителю домена.

## Применение владельцем — выполнено

Текущая сессия не имеет passwordless sudo. По VPS CLAUDE.md sudo-шаг выполняет Игорь; пароль не передавать в чат. Владелец выполнил этот шаг; повторно команду activate не запускать.

```bash
sudo bash /home/igor/.local/state/mamina-www/20261015T003038Z/activate.sh
```

Сценарий заново сверяет host, Caddy на диске и в памяти, исходные HTTP-коды, сервисы, конфиг, архив и хеши пакета. Если baseline изменился, останавливается до переключения. Создаёт root-owned backup в `/var/backups/mamina-www/20261015T003038Z`, копирует новый пакет в `/srv/mamina-www-releases/20261015T003038Z`, валидирует Caddy, атомарно заменяет конфиг и выполняет **reload**, без restart.

После переключения проверяет хеши всех публичных файлов и noindex, 404 для отсутствующих и служебных путей, health бота, Mini App, состояние сервисов и соответствие загруженного конфига. При ошибке после переключения автоматически восстанавливает предыдущий Caddy и проверяет исходный 503/health/Mini App. Результат — `result.json` рядом с пакетом. Старый web root остаётся нетронутым.

После успеха дополнительно открыть публичные главную, каталог и статью на desktop/mobile; пройти реальный Telegram-сценарий. HTTP-проверки не заменяют Telegram/платёжный E2E. Тестовые денежные операции не разрешены этой выкладкой.

## Ручной откат

```bash
sudo bash /home/igor/.local/state/mamina-www/20261015T003038Z/rollback.sh
```

Откат берёт root-owned план и конфиг, проверяет SHA текущего Caddy, возвращает точный прежний файл, validate/reload и HTTP 503/health/Mini App. Если другой оператор успел изменить Caddy, автоматическая перезапись отклоняется: нужен свежий diff. Новый каталог сохраняется для разбора. Не заменять весь apex на reverse_proxy бота.
