## Подача владельцем после сверки

1. Открыть [портал РКН](https://pd.rkn.gov.ru/) → раздел уведомлений → уведомление об
   обработке ПД. Прямая [форма](https://pd.rkn.gov.ru/operators-registry/notification/form/).
2. Выбрать оператора — физическое лицо. Внести реквизиты; отдельно по целям — категории
   субъектов/данных, основание, действия, способы, сроки. Проверить здоровье и места баз.
3. Проверить весь документ и отправить доступным способом с надлежащей подписью.
   Порядок зависит от доступной владельцу авторизации/подписи; сохранить номер и дату.
4. Проверить результат в реестре и обновлять сведения при изменениях. В этой сессии
   форма/реестр недоступны через веб-инструмент; названия кнопок внутри кабинета не проверены.

При фактической **трансграничной передаче** нужно отдельное уведомление по ст. 12.
Оно не заменяется уведомлением по ст. 22, согласием или словами «можем передавать» в
политике. Сначала установить получателей/страны, собрать необходимые сведения и проверить
применимый порядок начала передачи.
